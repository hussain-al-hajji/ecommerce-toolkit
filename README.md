# حقيبة التاجر الإلكتروني

دليل مجاني ومتجدد لكل ما يحتاجه التاجر الإلكتروني: منصات المتاجر، الأسواق الإلكترونية، بوابات الدفع، الشحن والتخزين، التمويل، التقارير، وغيرها — مع **لوحة تحكم مدمجة** لإدارة المحتوى ونشره دون الحاجة لكتابة أي كود.

موقع ثابت (HTML / CSS / JavaScript) بلا أي خطوة بناء، جاهز للاستضافة المجانية على **GitHub Pages**.

---

## هيكل المشروع

```
├── index.html              الموقع (الرئيسية + صفحات الأقسام + البحث)
├── admin/index.html        لوحة التحكم
├── data/site.json          كل محتوى الموقع (النصوص، الأقسام، المنصات، الروابط)
├── assets/
│   ├── css/site.css        الهوية البصرية للموقع
│   ├── css/admin.css       تنسيق لوحة التحكم
│   ├── js/icons.js         الأيقونات والشعار (SVG)
│   ├── js/site.js          منطق الموقع
│   ├── js/admin.js         منطق لوحة التحكم
│   ├── logos/              شعارات المنصات
│   ├── reports/            صور التقارير والإنفوجرافيك
│   └── uploads/            الصور المرفوعة من لوحة التحكم (تُنشأ تلقائياً)
└── favicon.svg
```

## التشغيل على جهازك

الموقع يقرأ المحتوى من `data/site.json`، لذا يجب تشغيله عبر خادم محلي (وليس بفتح الملف مباشرة):

```bash
python3 -m http.server 8000
```

ثم افتح: `http://localhost:8000` — ولوحة التحكم: `http://localhost:8000/admin/`

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub وارفع إليه هذه الملفات.
2. من المستودع: **Settings ← Pages**، واختر `Deploy from a branch`، والفرع `main`، والمجلد `/ (root)`.
3. بعد دقيقة سيكون الموقع متاحاً على: https://hussain-al-hajji.github.io/ecommerce-toolkit/
   ولوحة التحكم على: https://hussain-al-hajji.github.io/ecommerce-toolkit/admin/

## لوحة التحكم

الرابط: `/admin/`

**ما الذي يمكنك فعله:**
- إضافة الأقسام وتعديلها وترتيبها وإخفاؤها.
- إضافة المنصات والأدوات والتقارير: الاسم، الوصف، الشعار (رفع صورة مع ضغط تلقائي)، والروابط.
- نقل أي عنصر بين المجموعات والأقسام، ونسخه، وترتيبه.
- إدارة معارض صور التقارير.
- تعديل نصوص الصفحة الرئيسية، روابط نماذج «قيّم جاهزيتك» و«اقترح موقع»، ونبذة صاحب الفكرة وحساباته.
- لوحة معلومات تنبّه إلى العناصر بلا روابط أو بلا شعارات والأقسام الفارغة.
- تصدير المحتوى واستيراده كنسخة احتياطية.

**كيف يعمل الحفظ والنشر:**
1. كل تعديل يُحفظ تلقائياً **كمسودة** في متصفح جهازك.
2. زر **«معاينة»** يفتح الموقع بالمسودة قبل نشرها (`/?preview=1`).
3. زر **«نشر التغييرات»** يرفع الصور الجديدة وملف `data/site.json` مباشرة إلى المستودع، فيتحدث الموقع خلال دقيقة تقريباً.

**ربط لوحة التحكم بالمستودع (مرة واحدة لكل جهاز):**
1. من GitHub: **Settings ← Developer settings ← Personal access tokens ← Fine‑grained tokens ← Generate new token**.
2. في *Repository access* اختر مستودع الموقع فقط.
3. في *Repository permissions* امنح **Contents: Read and write**.
4. انسخ الرمز وأدخله في شاشة الدخول للوحة التحكم مع اسم المستخدم واسم المستودع.

> **الأمان:** صفحة لوحة التحكم عامة، لكن لا يمكن لأحد نشر أي تعديل بدون رمز الوصول الخاص بك. الرمز يُحفظ في متصفح جهازك فقط ولا يُرفع إلى المستودع. استخدم رمزاً مقيّداً بهذا المستودع وحده، ويمكنك إلغاؤه من GitHub في أي وقت.

## بنية ملف المحتوى `data/site.json`

```jsonc
{
  "site": { "name", "tagline", "intro": [], "readiness": {text,label,url}, "suggest": {text,label,url}, "author": {name, role, bio, socials: [{type,url}]} },
  "categories": [
    {
      "id": "e-commerce-platforms",       // يظهر في الرابط: #/c/e-commerce-platforms
      "title", "summary", "intro", "icon", "hidden",
      "groups": [
        {
          "id", "title", "subtitle", "note",
          "layout": "cards | list | gallery",
          "items": [ { "id", "name", "subtitle", "kicker", "desc": [], "source", "logo", "links": [{label,url}] } ],
          "images": [ { "src", "caption" } ]    // لمجموعات المعرض فقط
        }
      ]
    }
  ]
}
```

## روابط مفيدة داخل الموقع

- رابط مباشر لأي قسم: `#/c/<معرّف-القسم>`
- رابط مباشر لأي منصة داخل قسم: `#/c/<معرّف-القسم>/<معرّف-العنصر>`
- البحث: زر البحث أعلى الصفحة أو الضغط على `/`

تُحفظ تعديلاتك أولاً كمسودة على هذا الجهاز، ثم تُنشر إلى الموقع عبر مستودع GitHub الخاص بك.

كيف أحصل على رمز الوصول؟
  1. من GitHub افتح: Settings ← Developer settings ← Personal access tokens ← Fine‑grained tokens.
  2. اضغط Generate new token، واختر المستودع الخاص بالموقع فقط.
  3. من Repository permissions امنح صلاحية Contents: Read and write.
  4. انسخ الرمز والصقه هنا. يُحفظ الرمز في متصفح هذا الجهاز فقط.
